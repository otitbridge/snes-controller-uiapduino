# 確認ログの公開方針

P0の環境・ソース確認、P1のPC上のテスト、P2のビルド・全キー解放版の書き込みとMacでのUSB列挙の記録です。実キーの保持・解放やDeltaでの操作は未試験です。

- `p0-environment-2026-11-10.json`：実行コマンド、結果、参照ファイルのSHA-256。
- `p0-final-review-2026-11-10.json`：終了時のファイル比較と文書の確認結果。
- `p0-upstream-2026-11-10.json`：参照コアのタグ、コミット、ファイルのblob SHA、パッケージ索引。
- `p1-host-tests-2026-11-10.json`：ホストテストの条件・出力・ソースとホスト実行ファイルのSHA-256。未コミットのP1ソースはSHA-256で特定しています。
- `p2-build-2026-11-10.json`：専用環境の版・アーカイブ照合・2種類のビルド設定とサイズ・成果物とソースのSHA-256・バックエンドのホストテスト。P2のソースは実行時のSHA-256で特定しています。
- `p2-upload-neutral-2026-11-10.json`：全キー解放版の書き込み前後の対象情報、実行ログ、読み戻し検証、Macでのキーボード／マウス列挙。実機の接続位置・一時的なデバイス識別子は公開記録から除外しています。

環境確認ログと終了時確認ログは公開用にパスを置換しています。`<PROJECTS_DIR>` は3つの作業領域を置いた共通親ディレクトリ、`<HOME>` は開発者のホームディレクトリです。これらは説明用の表記であり、そのまま実行するコマンドではありません。各JSONの `publication` に置換内容を記録しています。

コマンドの結果・時刻・バージョン・ファイルのSHA-256は、パス表記の置換以外は維持しています。SHA-256は参照した元ファイルに対する値で、公開用JSON自体のハッシュではありません。

元ログは `local/` に手元で保持し、`.gitignore` で除外します。今後の記録でも、認証情報や個人の配置を含む元ログは直接コミットせず、公開用の内容を確認して保存します。

P2の生ログは `.local/logs/` に保持します。公開記録の診断で使う `<PROJECT_DIR>` はこのリポジトリのルートを意味します。ビルドしたBIN／ELF等は `.local/build/` に保持し、Gitへ追加していません。
