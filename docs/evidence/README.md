# 確認ログの公開方針

P0の環境・ソース確認、P1のPC上のテスト、P2のビルド・書き込みと最小HID入力、P3のSFC診断と実配線後の入力試験、P4のiPhone／Delta試験と、内蔵後・iPad・Delta更新版の追加確認の記録です。実施済みの条件と未確認の条件は各記録で区別します。

- `p0-environment-2026-11-10.json`：実行コマンド、結果、参照ファイルのSHA-256。
- `p0-final-review-2026-11-10.json`：終了時のファイル比較と文書の確認結果。
- `p0-upstream-2026-11-10.json`：参照コアのタグ、コミット、ファイルのblob SHA、パッケージ索引。
- `p1-host-tests-2026-11-10.json`：ホストテストの条件・出力・ソースとホスト実行ファイルのSHA-256。未コミットのP1ソースはSHA-256で特定しています。
- `p2-build-2026-11-10.json`：専用環境の版・アーカイブ照合・2種類のビルド設定とサイズ・成果物とソースのSHA-256・バックエンドのホストテスト。P2のソースは実行時のSHA-256で特定しています。
- `p2-upload-neutral-2026-11-10.json`：全キー解放版の書き込み前後の対象情報、実行ログ、読み戻し検証、Macでのキーボード／マウス列挙。実機の接続位置・一時的なデバイス識別子は公開記録から除外しています。
- `p2-manual-hid-2026-11-10.json`：手動単キー版の書き込みと読み戻し検証、ジャンパ線の接続訂正、ブラウザでの入力試験。Raw HID取得の失敗も記録し、PC本体のZキーによる確認をUIAPduinoの合格証拠へ含めません。
- `p3-sfc-diagnostic-2026-11-10.json`：SFC読み取りの全65,536通りのホストテスト、診断版ビルド、P2版とのBIN一致、Mac用取得ツール、実機へ書き込んだ試行の記録。SFC未接続での確認と、全12ボタンの実物試験を区別します。
- `p3-wiring-reference-2026-11-10.json`：本人申告のSFC基板番号・線色・信号とUIAPduino側端子の対応、独立した製作者の配線資料との照合。外部コネクターの番号を基板番号と区別します。
- `p3-connected-sfc-2026-11-10.json`：実配線後の無応答、本人による配線修正、全12入力・左右の長押し・同時押し・部分解放の診断記録。最初の右＋下入力と右単独の再試験を分け、この試験時点ではSFCからのキーボード出力は未統合と明記しています。
- `p3-sfc-keyboard-2026-11-10.json`：SFCキーボード統合、専用コアのパッチと適用先、ホストの割り込みモデル、ビルド・従来BINとの互換性、統合版の実機確認状態。
- `p4-iphone-delta-2026-11-10.json`：GBA実用試験、U04調査のファーム切り替え・ログ・比較、Delta公開ソース確認、D08〜D10の本人報告。U04・D09はユーザー裁定で未解決のまま許容、D10は30分ちょうどでPASS。追加報告で斜め・3入力以上とSNES全12入力の設定画面を確認（SNES実ゲームは未確認）。試行順の履歴と現在状態を分けています。
- `p4-commit-review-2026-11-10.json`：証跡整理時の再検証、記録済みローカルログ／BINとのハッシュ照合、コミット対象ソース・文書のハッシュと公開範囲。コミット `c2bfaf3` 時点のスナップショットであり、後続の本人報告・裁定による文書変更はこのハッシュの対象外です。

- `p4-final-normal-upload-2026-11-10.json`：通常版への切り替え、全セクタ読み戻し一致、起動とMacのUSB/HID列挙。切り替え後の操作試験とは区別します。

環境確認ログと終了時確認ログは公開用にパスを置換しています。`<PROJECTS_DIR>` は3つの作業領域を置いた共通親ディレクトリ、`<HOME>` は開発者のホームディレクトリです。これらは説明用の表記であり、そのまま実行するコマンドではありません。各JSONの `publication` に置換内容を記録しています。

コマンドの結果・時刻・バージョン・ファイルのSHA-256は、パス表記の置換以外は維持しています。SHA-256は参照した元ファイルに対する値で、公開用JSON自体のハッシュではありません。

P0の元ログは `docs/evidence/local/` に手元で保持し、`.gitignore` で除外します。今後の記録でも、認証情報や個人の配置を含む元ログは直接コミットせず、公開用の内容を確認して保存します。

P2の生ログは `.local/logs/` に保持します。公開記録の診断で使う `<PROJECT_DIR>` はこのリポジトリのルートを意味します。ビルドしたBIN／ELF等は `.local/build/` に保持し、Gitへ追加していません。

## P4記録の読み方

現在の判定・対象ファームは [検証結果](../validation.md)、未解決事項は [既知の問題](../known-issues.md)、作業再開時の前提は [開発記録](../development/README.md) を参照してください。P4 JSONの `current_device_firmware`、`open_issues`、`next_test`／`remaining` は各記録時点の状態です。`observations` は試行順の履歴で、途中のRUNNINGや試験準備の記述を現在稼働中という意味では使いません。全取得・書き込み監視は停止済みです。

以下の表は2026-11-10のP4終了時点です。別基板への書き込み・内蔵後確認・iPadの追加報告は後続の節を参照してください。

| ファーム | BINサイズ | P4終了時の状態 |
| --- | ---: | --- |
| P3統合版 | 5,360バイト | 初期iPhone試験で使用。現在は未搭載 |
| GET_REPORT対応の通常版（旧Backspace） | 5,496バイト | Mac全12キー・保持・部分解放・6→7→6を確認後、Tab版へ切り替え。現在は未搭載 |
| GET_REPORT対応の通常版（SELECT→Tab） | 5,496バイト | 現在搭載。読み戻し・起動・Mac SELECT/B、Delta GBAの登録・操作・同時押し・部分解放・再接続3回を確認 |

本人報告、ブラウザイベント、能動的なEP0取得、非排他的IOHID入力、ホストテストを別の証拠として扱います。USB線上の全パケット取得やiPhoneの独立ログはありません。時刻のない本人報告を測定時刻へ変換せず、要求した保持時間と取得できた時間も区別します。

P4の生ログ・BINも `.local/` に保持し、Gitには入れません。公開JSONには観測の抜粋とSHA-256を記録していますが、ハッシュだけで第三者が元ログ全体を再検証できるわけではありません。途中版のソースハッシュは当時の値を保ち、コミットレビュー記録も、その対象コミットとの照合に用います。後続の変更へ同じハッシュを適用しません。

- `p4-normal-regression-2026-11-10.json`：通常版へ切り替えた後の操作確認。旧Backspace通常版のMac全12キー・左右保持・部分解放・6→7→6入力はPASS。Tab通常版のiPhone操作・同時押し・部分解放・再接続3回も本人報告でPASS。Macログは正常終了し、評価時点の接頭部分と終了時の全体のハッシュを保存しています。

- `p4-select-tab-2026-11-10.json`：SELECTのSafari到達とDelta入力不応答、Tab対応版のビルド・書き込み・Mac／Delta回帰試験。Backspaceの設定表示とiOS 26入力方式変更に関する追加調査も記録し、観測と未確定の原因仮説を分けます。
