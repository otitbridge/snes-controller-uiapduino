# 資料の案内

このリポジトリは、UIAPduino V1.4を内蔵したSFC USBキーボードのソース・導入手順・動作確認結果を提供します。現在の構成と使い方は利用者向け資料、制作経緯と試験の履歴は開発記録にまとめています。

## 利用・製作する方へ

| 知りたいこと | 資料 |
| --- | --- |
| 機能、構成図、キー割り当て、確認環境 | [README](../README.md) |
| 必要な部品と内蔵用の収納構成 | [部品と構成](hardware.md) |
| 5本の配線と端子番号 | [配線](wiring.md) |
| ビルドからDelta設定まで | [導入手順](getting-started.md) |
| 開発環境、FQBN、書き込み、テスト | [ビルド詳細](build.md) |
| 同時押しの規則、入力確認、USB状態管理 | [ファームウェア仕様](sfc-keyboard.md) |
| 症状への対処と未確認事項 | [既知の問題](known-issues.md) |
| 実際に確認した試験と対象ファーム | [検証結果](validation.md) |

## 開発経緯を調べる方へ

[開発記録の索引](development/README.md) から、失敗・再試験、途中版の切り替え、原因調査、作業引き継ぎに進めます。記録には試行当時の状態が含まれるため、現在の利用手順は上表の資料を参照してください。

[公開JSON](evidence/README.md) は試験条件、結果の抜粋、BINとログのハッシュを記録しています。ブラウザイベント・HID取得・実機操作者の報告・ホストテストを区別しており、元ログ全体は同梱していません。

## 同梱範囲

自作ソース、テスト、補助スクリプト、コアへの管理パッチ、文書、公開用JSONを含みます。[MITライセンス](../LICENSE) と移植元の著作権表示を保持しています。コア・ツール等の依存物には各々のライセンスが適用されます。

`.local/` のツール・ビルド成果物・生ログや、機器固有ログの `docs/evidence/local/` はGit対象外です。ゲームROM・BIOSは同梱していません。配線・内部写真、内蔵加工図は未収録です。組立後の確認結果は製作者報告として記録し、独立した入力ログは同梱していません。
