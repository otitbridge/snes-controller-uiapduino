# 動作確認結果

ブレッドボード構成で、以下の動作検証を完了しています。接続時保持とロック中解放には [未解決の問題](known-issues.md) があり、筐体内蔵後・iPad・SNES実ゲームは未確認です。

確認日：2026-11-10。Macの入力はブラウザイベント等のログで確認し、iPhoneのゲーム操作は実機操作者の観察報告に基づきます。iPhone側の独立したイベント記録や時間計測はありません。

## Macでの入力確認

| 試験 | 結果 | 対象 |
| --- | --- | --- |
| 全12ボタンを単独で押下・解放 | 対応するキーが届き、各回全解放 | Backspace通常版 |
| 左右30秒以上の保持・解放 | 左34.785秒、右32.622秒。保持中断なし | Backspace通常版 |
| 右＋Y＋BからBだけ解放 | 3入力を6.343秒、右＋Yを2.254秒保持し全解放 | Backspace通常版 |
| 6→7→6入力 | Wの除外・復帰を2回確認し全解放 | Backspace通常版 |
| SELECT→Tabを3回 | 押下・解放を確認 | Tab通常版 |
| B→Zを1回 | 押下・解放を確認 | Tab通常版 |

保持時間はブラウザで観測した区間です。接点の実時間や入力遅延の測定値ではありません。初回の左保持が30秒未満だったため、基準を満たした再試験の値を掲載しています。

## ビルド・ホストテスト

通常構成とAddressSanitizer／UndefinedBehaviorSanitizerで、以下を検査しています。

- 12ビット入力全4,096通りのキー変換と、24,576通りの1ボタン解放。
- 16ビット入力全65,536通りのSFC読取モデルと、スケッチからUSB setterまでの経路。
- 実コアの共有状態公開、147,456回の割り込み挿入モデル、GET_REPORT応答・コピー保持。
- MCU向けのコンパイルと、固定版コア・依存ツールの照合。

再実行方法は [ビルド・テスト手順](build.md#pc上のロジックとバックエンドのテスト) を参照してください。ホストモデルの成功をUSB実時間や全端末の互換性保証とは扱いません。
